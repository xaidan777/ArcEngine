# MGLOTEK Cloud Blender Bridge
Это отдельная ветка репозитория ArcEngine. Основная ветка main и движок ArcEngine НЕ менялись.

## Что делает мост
GitHub Actions запускает временный Linux runner, устанавливает Blender *только на облачном runner*, генерирует редактируемый `.blend`, экспортирует `.glb`, и рендерит прозрачный 2.5D слой `birch_mid.png` (1900x470). В игре остается Python + pygame.

Для рендера не нужно устанавливать Blender, ComfyUI, UniMate или другие инструменты на свой ПК. Этот мост пока использует только Blender. Нейросетевой пайплайн ComfyUI/UltraTex/Wan требует GPU runner или отдельный оплачиваемый GPU-хост: обычный GitHub Actions runner не заменяет его.

## Как запустить
Открой Actions -> «MGLOTEK Cloud Blender - 2.5D levels». По умолчанию рендерится «Берёзовый двор». Файл результата находится в разделе Artifacts (доступен ограниченное время). В workflow есть режим «all» для 11 разных островов — он требует существенно больше CPU минут.

**Ветка не содержит файлов твоей игры и не меняет существующие сохранения.** Для установки PNG в локальную игру возьми `<theme>_mid.png` и пропусти через предусмотренный пайплайн замены среднего плана, проверяя размеры и расположение объектов.

Статус: сам скрипт проверен синтаксически, рендер на GitHub Actions нужно подтвердить по логам соответствующего run.
