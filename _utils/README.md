# _utils — инструменты разработки (в билд не попадают)

Папка исключена из сборки (`BUILD_EXCLUDE` в `tools/asset-scan.mjs`); игра о ней не знает.

## editor/ — редактор локации

Запуск — `editor.bat` в корне набора:

```
editor.bat                 # порт 8090 (или следующий свободный), откроет браузер
editor.bat 9100 --no-open  # свой порт, без браузера
```

Адрес: `http://localhost:8090/_utils/editor/`. Нужен только Node.

- **Слева** — локация в 3D на тех же `World3D`/`Terrain3D`/`Location3D`/`CameraControl`,
  что игра. Тулбар: «Свободная камера» (WASD — полёт вдоль взгляда, Q/E — вниз/вверх,
  ПКМ — осмотр, ЛКМ — орбита, средняя или Shift+ЛКМ — панорама, колесо — зум к курсору)
  и «Игровая камера» (ровно камера игры: тот же полёт, ЛКМ — ввод игры, пределы — по
  `CAMERA_LIMITS`), «↺ Старт камеры» (R), режим гизмо «Перемещение / Поворот / Масштаб»
  (1/2/3), «toon-шейдер» (`WORLD3D_TOON`). Клик по объекту выбирает его, гизмо двигает,
  поворачивает и масштабирует выбранный. Ctrl+Z / Ctrl+Shift+Z — отмена и повтор правок.
- **Справа, вкладка Global Settings** — инспектор `Constants.js`: камера, toon, контур и
  обводка, солнце, тени, небо и туман, материалы, локация и рельеф. Группы при запуске
  свёрнуты, поиск их раскрывает. Правка видна сразу; «Сохранить» (Ctrl+S) точечно патчит
  числа в `Constants.js`, перед записью — бэкап в `_utils/.backups/`.
- **Справа, вкладка Objects** — объекты локации (`Objects.js`, их же показывает игра):
  «Импорт модели…» (`.fbx` или `.glb` со скелетом и клипами; системный диалог открывается в `assets/models/`, файл не из проекта
  копируется туда), список, свойства выбранного (имя, вид, позиция, поворот, масштаб),
  «Показать» (F), «Дублировать» (Ctrl+D), «Удалить» (Del), «Сохранить в Objects.js».
- **Справа, вкладка UI** — интерфейс игры (`UILayout.js`): тексты, панели, шкалы и кнопки видны поверх
  вида; элемент двигается драгом, размер — за маркеры рамки, стрелки — на 1 px (с Shift — 10).
  Якорь (9 точек экрана), цвета, шрифт и id — в свойствах; «Сохранить в UILayout.js» пишет файл.
  Код игры берёт элемент по id: `UI.get('score').setText('10')`.
- **Справа вверху** — язык интерфейса EN/RU (по умолчанию английский, выбор запоминается).

Устройство, добавление константы и ловушки — скилл `editor` (`claude/skills/editor/SKILL.md`).
