# Карты и ландшафт в редакторе

Запуск: `./editor.sh` (Linux/macOS) или `editor.bat` (Windows). Откройте **адрес из терминала**: если 8090 занят, сервер выбирает следующий свободный порт. После обновления серверного кода перезапустите сервер; F5 обновляет только клиент. API редактора — версия 21.

Верхняя панель: выбор карты, новая карта, «Сохранить как…», удаление карты. Новая карта поддерживает размеры 2048 и 4096, плоскость, холмы или PNG высот, отдельное включение дорог и скайлайна. Переключение предупреждает о несохранённых изменениях. Сохранение объектов и уровня теперь пишет выбранную карту, а не глобальный `Objects.js`.

`Ctrl+A` выбирает модели, модульные строения, фоновые дороги/здания/камни и маркеры. `Shift`/`Ctrl` + клик добавляет/исключает элемент. `Delete` и `Backspace` удаляют выбор. В текстовых полях эти сочетания остаются за браузером. «Очистить карту» позволяет отдельно удалить слои и сбросить рельеф; операция подтверждается диалогом с флажками. Пустые списки и удалённые маркеры сохраняются как пустые, без подстановки стандартного набора. Если спавн отсутствует, игровой тест начинает в центре карты.

На вкладке «Ландшафт» включите кисть. Доступны поднятие, опускание, сглаживание, выравнивание и шум. ПКМ опускает землю, ЛКМ применяет выбранный режим. Размер, сила и высота площадки задаются в панели. Пока кисть выключена, работают обычные управление камерой и выбор объектов.

Импорт: PNG 8 бит или нечересстрочный grayscale PNG 16 бит. Для 16 бит исходные значения читаются без преобразования в 8-битный Canvas. Диапазон min/max задаёт перевод яркости в игровые высоты. Экспорт — PNG 8 бит с указанным диапазоном. Сам JSON уровня сохраняет точные значения высот, поэтому сохранение/загрузка карты не квантует скульптинг. RAW и чересстрочный PNG 16 бит не поддерживаются.

`assets/levels/maps.json` — реестр; `/api/maps` также сканирует файлы уровней. Каждый JSON содержит ID, имя, размеры, terrain, environment, props, districtStructures, spawn/extraction/hatch и массивы enemies/containers/drives. Поле terrain.samples хранит высоты сетки с nx/ny/cell; terrain.heightmap позволяет использовать PNG. environmentDeleted хранит удалённые процедурные элементы. Новые карты не изменяют старые; сохранения и удаление создают копии в `_utils/.backups/`. Основную default_raid нельзя удалить из пула.

«Play Raid» сохраняет текущую карту и открывает её непосредственно в игре. Выбор локации также доступен в главном меню и на экране десанта. Пользовательские карты запускаются локально; сетевой матчмейкинг продолжает использовать серверную default_raid.

Проверки: `node tools/check.mjs --tests`, `node tools/check.mjs --types`. Тесты API используют отдельные временные каталоги и случайные порты, не меняя рабочие карты. В сборку включаются реестр, уровни и их ресурсы.
