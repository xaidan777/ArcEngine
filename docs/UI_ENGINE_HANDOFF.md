# Зависимости UI от движка и визуальных ресурсов

Дата: 2026-09-20.

## Ошибка проверки типов вне UI

Команда `node tools/check.mjs --types` обнаружила TS2552 в `js/World3D.js:268` и `:269`: имя `Instances3D` не найдено. Реализация находится в `js/Instances3D.js`. Проверить включение скрипта в список проверки и объявление глобального класса; не заменять типы на произвольный `any` только ради зелёной проверки. Ошибка присутствует в проверке игры и редактора.

## Графика станций и предметов

В текущем проходе карточки станций получили локальные SVG-схемы без внешних загрузок и дополнительных 3D-рендереров. Для окончательной художественной версии нужны собственные изображения верстаков, портреты торговцев и превью предметов Blackwater. Не переносить изображения и фирменную палитру ARC Raiders в продукт.

Желаемый набор: один превью-атлас предметов, изображения станций разных категорий, отдельная сцена/фон мастерской. Указать размеры, прозрачность, авторство и лицензии. Превью должны различаться по силуэту, а не только цвету редкости. Не создавать отдельный живой WebGL canvas для каждой карточки.

## Граница выполненной проверки

Сняты локальные скриншоты компонентов LoadoutScreen на 1920×1080 и 1366×768, а также выбора станций и настроек на 1366×768. Они используют реальные скрипты и CSS с тестовыми данными, без Playwright. Это проверка компоновки, не E2E работающего сервера и не измерение FPS игры.

Файлы текущего визуального прохода: `/tmp/arc-loadout-1920.png`, `/tmp/arc-loadout-1366.png`, `/tmp/arc-workshop-1366.png`, `/tmp/arc-settings-1366.png`. Временный стенд `/tmp/arc-desktop-review.html` не включён в сборку. Изображения являются промежуточными: после их просмотра дополнительно убраны фиктивное расширение склада и неверный индикатор пустой аугментации, уточнены отступы настроек.

Регрессионные проверки: `tests/loadout-navigation.test.mjs` (единственный обработчик Tab/Escape), `tests/menu-system.test.mjs` (раздельные оператор/сводка, серверная статистика, запрет локальных онлайн-продаж), `tests/ui.test.mjs` (отсутствие повторных DOM-записей при неизменном HUD), `tests/online-client.test.mjs` (обновление серверного баланса). Тесты транспорта работают с реальным локальным тестовым сервером, а не продуктивными аккаунтами.

Остаётся визуальный проход в реальном клиенте после интеграции серверного инвентаря: полный рюкзак, длинные русские названия, все станции, социальные запросы, HUD боя, карта, обыск, успешная/неуспешная эвакуация. Проверить frame time и отсутствие лишних обновлений скрытых экранов на целевом ПК.
